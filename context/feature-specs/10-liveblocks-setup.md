Real-Time Collaboration Infrastructure (Liveblocks)GoalEstablish the WebSocket real-time synchronization backend and type architecture using Liveblocks. This layer enables sub-second multi-user presence (cursors), locks active nodes during edits, and visualizes when the AI agent is actively modifying the canvas.1. Liveblocks Node Client & Palette Helper (src/lib/liveblocks.ts)Create a server-side cached Liveblocks client singleton. Secured Authentication Handshake (POST /api/liveblocks-auth)Create a protected Route Handler endpoint to authorize incoming client WebSocket connection requests securely.Authentication Steps:Clerk Verification: Validate the session using Clerk's token client wrapper. If the request lacks a valid user token, abort processing immediately and return an HTTP 401 Unauthorized status response.Workspace Perimeter Access Check: Extract the requested project room ID parameter from the body payload.
